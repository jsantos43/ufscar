# Implementando um decodificador de 16 bits com prioridade 

O objetivo desta simulação é [implementar um codificador de 16 bits em Verilog Estrutural](top.sv), a partir de um arranjo de [codificadores de 4 bits](priority_encoder.sv) e um [multiplexador](mux8to2.sv) fornecidos.

> Para isso, você não pode usar Verilog Comportamental.
